Python 智能记账分析服务
========================

一、功能说明
----------

本项目是一个基于 Python 的智能记账分析服务，为记账系统提供数据驱动的智能分析能力。主要功能包括：

1. 月度趋势对比（环比分析）
   - 对比本月与上月的收支数据
   - 计算各消费分类的变化幅度和百分比
   - 生成直观的趋势对比报告

2. 异常消费检测
   - 基于统计学 Z-score 方法检测异常消费
   - 分析最近 6 个月的历史数据
   - 识别超出 2 倍标准差的异常消费日
   - 列出异常日的详细消费明细

3. 月末支出预测
   - 使用加权移动平均法预测月末总支出
   - 结合本月已消费金额和历史月度数据
   - 提供置信度评估（高/中/低）
   - 与用户预算对比，给出超支预警

4. 分类深度洞察
   - 分析各消费分类的占比变化
   - 计算单笔消费均值
   - 根据数据生成针对性的消费建议

5. 综合分析报告
   - 汇总以上所有分析结果
   - 生成自然语言摘要，便于用户理解
   - 包含趋势、异常、预测、建议等完整信息

6. LLM 深度分析（可选）
   - 支持接入大语言模型（DeepSeek、OpenAI 等）
   - 基于用户记账数据生成专业财务分析报告
   - 提供个性化的省钱建议


二、技术实现
----------

1. 技术栈
   - Python 3.12：主要开发语言
   - Flask：轻量级 Web 框架，提供 RESTful API
   - NumPy：数值计算库，用于数据处理
   - SciPy：科学计算库，用于统计分析
   - SQLite：直接读取记账系统的数据库

2. 核心算法

   (1) 环比分析算法
       - 从数据库获取本月和上月的分类消费数据
       - 计算各分类的金额变化和百分比变化
       - 按变化幅度排序，突出涨幅最大的分类

   (2) 异常检测算法（Z-score）
       - 收集最近 6 个月的每日消费数据
       - 计算均值（mean）和标准差（std）
       - Z-score = (当日消费 - 均值) / 标准差
       - Z-score >= 2.0 视为异常消费

   (3) 月末预测算法（加权移动平均）
       - 计算本月日均消费 = 本月已消费 / 已过天数
       - 简单预测 = 日均消费 × 本月天数
       - 加权预测 = 简单预测 × 当前权重 + 历史月均 × 历史权重
       - 越到月末，当前数据权重越高

   (4) 建议生成算法
       - 根据分类占比变化生成建议
       - 根据单笔消费均值生成建议
       - 针对特定分类（餐饮、交通、购物等）提供专属建议

3. API 设计
   - 采用 RESTful 风格设计
   - 所有接口支持 year 和 month 参数指定分析月份
   - 返回统一的 JSON 格式：{code: 200, data: {...}}

4. LLM 集成
   - 支持 OpenAI 兼容接口
   - 自动适配不同平台的认证方式（api-key / Bearer token）
   - 将结构化数据组装成自然语言提示词
   - 调用大模型生成专业的财务分析报告


三、代码结构
----------

python-ai/
├── app.py                # Flask 主应用，定义 API 路由
├── analyzer.py           # 分析引擎，核心业务逻辑
├── db_reader.py          # 数据库读取层，封装 SQL 查询
├── llm_client.py         # LLM 客户端，调用大模型 API
├── ai_config_manager.py  # 配置管理，处理 LLM 配置
├── requirements.txt      # Python 依赖清单
└── README.md             # 项目说明文档

各模块职责：

1. app.py（Flask 主应用）
   - 初始化 Flask 应用和 CORS
   - 定义 9 个 API 路由接口
   - 处理请求参数和响应格式
   - 捕获异常并返回错误信息

2. analyzer.py（分析引擎）
   - month_comparison()：月度环比对比
   - detect_anomalies()：异常消费检测
   - predict_month_end()：月末支出预测
   - category_insights()：分类深度洞察
   - generate_summary()：综合分析报告
   - llm_analysis()：LLM 深度分析

3. db_reader.py（数据库读取层）
   - get_connection()：获取 SQLite 连接
   - get_transactions()：查询交易记录
   - get_monthly_expenses()：获取月度支出
   - get_category_expenses()：获取分类支出
   - get_daily_expenses()：获取每日支出
   - get_settings()：获取用户设置

4. llm_client.py（LLM 客户端）
   - call_llm()：调用 LLM API
   - 支持 DeepSeek、OpenAI、小米 MiMo 等平台
   - 自动适配不同认证方式

5. ai_config_manager.py（配置管理）
   - load_config()：加载配置（.env.local 优先）
   - save_config()：保存配置到 JSON 文件
   - get_config_status()：获取配置状态


四、运行方式
----------

1. 安装依赖
   pip install -r requirements.txt

2. 启动服务
   python app.py

3. 访问接口
   http://localhost:5001/api/ai/health

服务默认运行在 5001 端口，可通过 API 接口获取分析结果。
